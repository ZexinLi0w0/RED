# RED
ATC’23 Robotic Environmental Dynamics (RED)

## Idea

1. Identify an experimental robotic scenario that highlight potential environmental dynamics 

2. Target three observations or challenges: 

a. workload structure change (mainly adding or sometimes reducing nodes into the graph, or even simply structural changes), coupled with the fact that end to end deadline should never change 

b. potentially weak candidate: fundamental criticality changes at runtime; multi-tasking, mixed CPU/DNN workloads; MIMO, 

c. memory issue
due to hardware constraints
