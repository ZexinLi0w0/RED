# New Scenario Launch Commands

Each command runs `main.py` with the appropriate task config for a given device, scenario, deadline (tight/loose), and scheduling approach. Replace the approach flag as needed.

## Urban Navigation

### AGX

- `python main.py --config handler-config.json --task TaskConfigs/simo/new_scenarios/agx_tight_urban_navigation.json --approach baseline`
- `python main.py --config handler-config.json --task TaskConfigs/simo/new_scenarios/agx_tight_urban_navigation.json --approach feedback`
